C-partition: A File Splitting and Installation Tool

*Description*

C-partition is a Python-based tool designed to split large files into smaller chunks and store them across two different locations or drives. This utility enables users to access and run files even when there is insufficient storage space on a single drive.

*Technologies Used*

- Python

*Setup Instructions*

Currently, there are no specific setup instructions. Simply run the Python script to use the tool.

*Usage Example*

1. Split a large file into customizable chunk-size(s) and store them across two drives (e.g., local drive and external drive).
2. Access and run the file directly from both locations without reconstructing it.

*Features*

- Splits files into customizable chunks
- Stores chunks in two specified locations
- Creates a loader script to reassemble and run the file
- Supports various file types (PDF, video, audio, executable)
